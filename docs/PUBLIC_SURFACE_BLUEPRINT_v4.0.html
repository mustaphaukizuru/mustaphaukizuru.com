Public Surface Blueprint v4.0

Audit of D:\Github\mustaphaukizuru-repo (branch feat/home-platform-showcase, HEAD 620f2d4) against PROJECT INSTRUCTIONS v4.0 §05–§07 · 3 Sep 2026

The site does not need new pages; it needs the four service pages finished to the §07 blueprint, one audience page for schools, and a media system that currently does not exist. The build is already ahead of the v4.0 documents in engineering (cookie sessions, CSRF, Spanish-first catalogue, booking, lead capture, Lighthouse gates) and behind them in exactly the two places the documents say outrank everything: the visual-first mandate and the service-page blueprint. /services/:slug today implements roughly 3 of the 8 mandated sections; the offerings render as a <ul>; the category "object" is an icon in a tinted box; there is no problem-framing diagram, no outcome tiles, no case evidence, no adjacent-category cards. The brand line says STEM & School Solutions and the description names school administrators as an entry audience — there is no page for them. Photography is one headshot set; there is zero video; there is no visual-asset registry.

Five contradictions between the code and v4.0 must be decided before any of this is built, or the work will be done twice. They are listed first.

Change the header's primary button from Store to Book a call.
